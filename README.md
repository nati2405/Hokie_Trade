# Hokie_Trade

Virginia Tech students regularly buy, sell, or trade goods and services with one another, like textbooks, dorm furniture, tutoring, event tickets, rides, and other everyday items, but no dedicated platform supports this exchange within the campus community. Students currently rely on general-purpose tools such as Facebook Marketplace, GroupMe chats, Instagram pages, or physical flyers, none of which verify that the other party is even a Virginia Tech student.
